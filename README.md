# 📱 یوتیوب‌یار — دستیار همه‌کاره مانیتایز یوتیوب

اپلیکیشن اندروید نیتیو (Kotlin + Jetpack Compose) که کاربر را از روز اولِ ساخت کانال یوتیوب تا رسیدن به مانیتایز (۱۰۰۰ سابسکرایبر + ۴۰۰۰ ساعت واچ‌تایم) همراهی می‌کند.

## ✨ امکانات

| ماژول | توضیح |
|---|---|
| 🏠 داشبورد مانیتایز | دو حلقه پیشرفت (سابسکرایبر و ساعت)، نمودار روند، تخمین روز رسیدن به مانیتایز، مایل‌استون‌ها و شرایط رسمی YPP |
| 📊 تحلیل کانال | تحلیل هر کانال با YouTube Data API v3 (سابسکرایبر، میانگین بازدید، نرخ تعامل، بینش‌های خودکار) + مقایسه با رقیب |
| 🤖 هوش مصنوعی | ۵ ابزار کاملاً **آفلاین**: عنوان سئوشده با امتیاز، توضیحات کامل با تایم‌استمپ، تگ‌ها، اسکریپت‌نویس با هوک، ایده‌یاب + سرویس اختیاری Gemini/OpenAI/DeepSeek با کلید کاربر |
| ✅ نقشه راه | ۴ فاز × ۱۰ وظیفه از روز اول تا ارسال درخواست مانیتایز + وظایف روزانه + یادآور نوتیفیکیشن |
| 🎓 آکادمی | ۱۲ درس کاربردی دوزبانه (فارسی/انگلیسی) با نکات کلیدی |
| 💎 اشتراک ویژه | خرید اشتراک ماهانه/سالانه از **کافه‌بازار** و **مایکت** (IAB v3) + آنلاک ۲۴ ساعته رایگان با تبلیغ جایزه‌ای تپسل |
| 📢 تبلیغات تپسل | بنر + میان‌پرده + جایزه‌ای (وقتی کلیدها تنظیم نشوند، تبلیغات خودکار غیرفعال است) |

ساختار معماری: **MVVM + Jetpack Compose + Room + DataStore + Hilt + Retrofit + WorkManager** — بدون WebView و بدون سرور؛ همه‌چیز روی دستگاه.

## 🛠 راه‌اندازی و بیلد

### پیش‌نیازها
- **Android Studio** (نسخه Koala یا جدیدتر — هر نسخه‌ای با AGP 8.5)
- JDK 17 (داخل Android Studio به‌صورت پیش‌فرض هست)
- اینترنت برای دانلود Gradle و کتابخانه‌ها

### مراحل
1. پوشه پروژه را در Android Studio باز کنید (`File > Open` → پوشه `YouTubeYar`).
2. صبر کنید تا **Gradle Sync** تمام شود (اولین بار چند دقیقه طول می‌کشد).
3. دکمه ▶️ را بزنید تا روی گوشی/شبیه‌ساز اجرا شود.

برای گرفتن خروجی انتشار: `Build > Generate Signed App Bundle / APK > APK` → ساخت keystore جدید → Release.

## 🔑 تنظیمات ضروری قبل از انتشار (خیلی مهم!)

### ۱) تبلیغات تپسل
1. در [پنل تپسل](https://tapsell.ir) ثبت‌نام کنید و یک اپلیکیشن با پکیج‌نیم `com.youtubeyar.app` بسازید.
2. **کلید اپلیکیشن** و ۳ زون (بنر، میان‌پرده، جایزه‌ای) را بسازید.
3. مقادیر را در فایل `app/src/main/res/values/strings.xml` (بالای فایل) جای‌گذاری کنید:

```xml
<string name="tapsell_app_key" translatable="false">کلید اپلیکیشن شما</string>
<string name="tapsell_zone_banner" translatable="false">زون بنر</string>
<string name="tapsell_zone_interstitial" translatable="false">زون میان‌پرده</string>
<string name="tapsell_zone_rewarded" translatable="false">زون جایزه‌ای</string>
```

> ⚠️ نکته: تا وقتی این کلیدها خالی باشند، تبلیغات نمایش داده نمی‌شود و اپ بدون خطا کار می‌کند. اگر نسخه SDK تپسل امضای متدها را تغییر داده باشد، فقط فایل `TapsellAdsManager.kt` را مطابق [مستندات رسمی تپسل](https://docs.tapsell.ir/android/) به‌روز کنید — تمام کد تبلیغات در همین یک فایل ایزوله است.

### ۲) پرداخت کافه‌بازار و مایکت
- محصولات اشتراک با دو شناسه تعریف شده‌اند: `premium_month` و `premium_year`.
- در پنل کافه‌بازار و مایکت، دو محصول **اشتراکی** با همین شناسه‌ها بسازید.
- پروتکل هر دو فروشگاه همان **In-App Billing v3** استاندارد است (کد در `billing/`). پکیج فروشگاه در زمان اجرا خودکار تشخیص داده می‌شود.
- (اختیاری) کلید RSA عمومی کافه‌بازار را از پنل بگیرید و در تنظیمات خودِ اپ (بخش کلیدها) وارد کنید تا خریدها را امضاسنجی کنید.
- اگر خواستید شناسه محصولات را عوض کنید: `billing/BillingManager.kt` → ثابت‌های `SKU_MONTH` و `SKU_YEAR`.

### ۳) تحلیل کانال (YouTube Data API)
1. وارد [Google Cloud Console](https://console.cloud.google.com) شوید → پروژه جدید بسازید.
2. در بخش **APIs & Services → Library** سرویس **YouTube Data API v3** را Enable کنید.
3. در **Credentials** یک **API Key** بسازید (محدودیت: فقط YouTube Data API).
4. کلید در خود اپ (تنظیمات → کلیدها) وارد می‌شود — لازم نیست در کد باشد.

> آمار خصوصی مثل ساعت واچ‌تایم از API عمومی یوتیوب قابل دریافت نیست (فقط در YouTube Studio دیده می‌شود)؛ به همین دلیل ردیاب پیشرفت بر اساس ثبت دستی کاربر کار می‌کند — همان عددی که Studio نشان می‌دهد.

### ۴) هوش مصنوعی آنلاین (اختیاری)
پیش‌فرض اپ، موتور آفلاین داخلی است که بدون اینترنت کار می‌کند. اگر خواستید کیفیت بالاتر برود، کاربر می‌تواند در تنظیمات یکی از سرویس‌های **Gemini** (کلید رایگان از aistudio.google.com) یا **OpenAI** یا **DeepSeek** را با کلید خودش فعال کند.

## 🌐 دو زبانه بودن
- زبان پیش‌فرض: **فارسی** (`values/strings.xml`)
- زبان انگلیسی: `values-en/strings.xml` (خودکار وقتی زبان گوشی انگلیسی باشد)
- روی اندروید ۱۳+ کاربر می‌تواند از تنظیمات سیستم، زبان اپ را جدا از زبان گوشی تنظیم کند.
- برای تغییر نام اپ: `app_name` در هر دو فایل strings.

## 📂 ساختار کد

```
app/src/main/java/com/youtubeyar/app/
├── MainActivity.kt / YouTubeYarApp.kt   ← ورودی و Application (Hilt)
├── di/            ← تزریق وابستگی (Room, Retrofit)
├── data/          ← Room (پیشرفت، چک‌لیست، تاریخچه AI) + DataStore + محتوای نقشه راه و آکادمی
├── billing/       ← IabHelper (IAB v3) + BillingManager (بازار/مایکت)
├── ads/           ← TapsellAdsManager (بنر/میان‌پرده/جایزه‌ای) + بنر Compose
├── ai/            ← موتور آفلاین + سرویس Gemini/OpenAI/DeepSeek
├── youtube/       ← کلاینت YouTube Data API v3 + تحلیل کانال
├── work/          ← یادآور روزانه (WorkManager)
└── ui/            ← تم، ناوبری، کامپوننت‌ها و ۸ صفحه
```
