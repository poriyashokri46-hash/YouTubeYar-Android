# چک‌لیست آمادگی انتشار یوتیوب‌یار

این سند وضعیت کار را ثبت می‌کند. موردی فقط زمانی «تأییدشده» محسوب می‌شود که با ساخت، آزمون یا آزمایش واقعی پشتیبانی شود؛ وجود کد به‌تنهایی کافی نیست.

## دروازهٔ اول: ساخت و کیفیت پایه
- [ ] اجرای موفق `./gradlew assembleDebug`
- [ ] اجرای موفق `./gradlew testDebugUnitTest`
- [ ] بررسی Android Lint و دسته‌بندی هشدارهای مهم
- [ ] نصب APK روی دستگاه واقعی و اجرای سناریوهای اصلی
- [ ] ثبت نسخهٔ JDK، Gradle و نتیجهٔ CI

## هوش مصنوعی و داده‌های یوتیوب
- [ ] بررسی ورودی خالی/بسیار طولانی و متن فارسی/انگلیسی
- [ ] اجرای درخواست آنلاین روی dispatcher مناسب و تعیین timeout
- [ ] نمایش خطای روشن در قطع اینترنت، خطای HTTP و پاسخ نامعتبر
- [ ] مشخص‌کردن محدودیت‌های موتور آفلاینِ مبتنی بر الگو
- [ ] تأیید آمار کانال از API واقعی و تفکیک دادهٔ دستی از دادهٔ زنده
- [ ] بررسی سهمیه و نگهداری امن کلیدهای API

## درآمدزایی
- [ ] ثبت App Key و Zone IDهای واقعی تپسل در پیکربندی امن
- [ ] آزمایش درخواست، نمایش، بستن و خطای هر قالب تبلیغ
- [ ] اعطای جایزه فقط از callback معتبر SDK پس از تکمیل تبلیغ
- [ ] تأیید محصول‌ها و شناسه‌های SKU با تنظیمات واقعی فروشگاه
- [ ] اعتبارسنجی خرید با روش مورد پشتیبانی فروشگاه؛ عدم اعتماد به دادهٔ محلی به‌تنهایی
- [ ] آزمایش لغو خرید، خرید تکراری، بازیابی و انقضای اشتراک
- [ ] تأیید رفتار بدون فروشگاه یا بدون اینترنت

## امنیت، حریم خصوصی و انتشار
- [ ] تکمیل سیاست حریم خصوصی با اطلاعات واقعی ناشر و راه تماس
- [ ] اطمینان از نبود توکن، کلید خصوصی یا اطلاعات محرمانه در مخزن
- [ ] بازبینی مجوزها، پشتیبان‌گیری و نگهداری داده‌های کاربر
- [ ] بررسی مهاجرت پایگاه داده و جلوگیری از حذف ناخواستهٔ داده‌ها
- [ ] ساخت نسخهٔ Release و بررسی امضا/پیکربندی انتشار
- [ ] بررسی الزامات فعلی کافه‌بازار و SDKهای تبلیغاتی
- [ ] آزمایش نصب/ارتقا روی حداقل نسخهٔ پشتیبانی‌شده و نسخهٔ جدید اندروید

## وضعیت فعلی
- وضعیت تأییدشده: سورس روی مخزن گیت‌هاب قابل دسترسی است.
- در انتظار CI: ساخت، آزمون‌ها و lint باید اجرا شوند.
- در انتظار اطلاعات مالک: کلیدها و Zone ID واقعی تپسل و شناسه‌های دقیق محصولات فروشگاه.
- در انتظار آزمایش دستگاه: پرداخت واقعی، نمایش تبلیغ و تجربهٔ کاربری.
- هشدار: این پروژه تا زمان بسته‌شدن موارد مسدودکننده، آمادهٔ انتشار نهایی تلقی نمی‌شود.
